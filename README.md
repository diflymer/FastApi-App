# Глоссарий терминов ВКР

API для управления глоссарием терминов ВКР, разработанный с использованием FastAPI и SQLite.

## Описание

Данный проект реализует REST API для глоссария терминов с полным CRUD функционалом. Сервис использует:
- **FastAPI** - веб-фреймворк для создания API
- **SQLite** - легковесная реляционная база данных
- **SQLAlchemy** - ORM для работы с базой данных
- **Pydantic** - валидация входных данных и формирование схем

## Функциональность

Сервис поддерживает следующие операции:
- Получение списка всех терминов
- Получение информации о конкретном термине по ключевому слову
- Добавление нового термина с описанием
- Обновление существующего термина
- Удаление термина из глоссария

## Установка и запуск

### Локальный запуск

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/diflymer/FastApi-App.git
cd fastapi-glossary
```

2. **Создайте виртуальное окружение:**
```bash
python -m venv venv
```

3. **Активируйте виртуальное окружение:**
```bash
# Для Windows:
venv\Scripts\activate

# Для Linux/Mac:
source venv/bin/activate
```

4. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

5. **Запустите приложение:**
```bash
uvicorn main:app --reload
```

Сервис будет доступен по адресу: http://127.0.0.1:8000

## Документация API

После запуска приложения откройте браузер и перейдите по адресу:
- **Swagger UI**: http://127.0.0.1:8000/docs
- **ReDoc**: http://127.0.0.1:8000/redoc

## Эндпоинты API

### Получить все термины
```
GET /terms
```
Возвращает список всех терминов в глоссарии.

### Получить конкретный термин
```
GET /terms/{term_name}
```
Возвращает информацию о конкретном термине по его имени.

### Добавить новый термин
```
POST /terms
```

### Обновить термин
```
PUT /terms/{term_name}
```

### Удалить термин
```
DELETE /terms/{term_name}
```

## Структура базы данных

При первом запуске автоматически создается база данных `glossary.db` с таблицей `terms`:

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Первичный ключ |
| name | VARCHAR | Название термина (уникальное) |
| definition | TEXT | Определение термина |

## Начальные данные

При первом запуске в базу данных автоматически добавляются следующие термины:
- MP
- MiniApps
- HTML
- js

## Тестирование

Для тестирования API можно использовать curl или любой HTTP клиент:

```bash
# Получить все термины
curl http://127.0.0.1:8000/terms

# Получить конкретный термин
curl http://127.0.0.1:8000/terms/API

# Добавить новый термин
curl -X POST "http://127.0.0.1:8000/terms" \
     -H "Content-Type: application/json" \
     -d '{"name": "REST", "definition": "Архитектурный стиль"}'

# Обновить термин
curl -X PUT "http://127.0.0.1:8000/terms/js" \
     -H "Content-Type: application/json" \
     -d '{"definition": "Обновленное определение"}'

# Удалить термин
curl -X DELETE http://127.0.0.1:8000/terms/js
```
